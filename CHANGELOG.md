## [1.0.0] – 2026-08-26

### Добавлено
- Основной скрипт `isin_calendar.py` для автоматической синхронизации купонов облигаций с Google Календарём.
- Чтение списка ISIN из текстового файла (передаётся как аргумент командной строки).
- Получение актуальных данных по купонам с публичного API Московской биржи (MOEX).
- Автоматическое создание событий в Google Календаре с указанием:
  - названия облигации,
  - даты выплаты,
  - суммы купона в рублях.
- Удаление событий для ISIN, которые были удалены из файла со списком.
- Предотвращение дублирования событий при повторных запусках.
- Установка напоминания за 24 часа до даты купонной выплаты.
- Файл `requirements.txt` со всеми необходимыми зависимостями и их точными версиями.
- Подробный `README.md` с инструкциями по установке, настройке Google Cloud Console, запуску и примерам использования.
- Лицензия MIT с указанием автора (Aleksey Mortin).
- Файл `.gitignore` для защиты конфиденциальных файлов (`credentials.json`, `token.json`, `__pycache__/` и др.).
- Пример файла `isin_list_example.txt` в папке `examples/`.
- Поддержка автоматической авторизации в Google через OAuth 2.0 с сохранением `token.json` для повторных запусков.
- Обработка пагинации при получении событий из календаря (до 2500 событий за раз).

### Исправлено
- Исправлено имя скрипта в сообщении о неправильном использовании (было `add_coupons_to_calendar.py`, стало `isin_calendar.py`).
- Добавлена проверка наличия файла `credentials.json` перед запуском – теперь скрипт выдаёт понятную ошибку, если файл отсутствует.
- Исправлены временные метки в запросах к календарю: переход на UTC (вместо фиксированного `+03:00`) для корректной работы пользователей в разных часовых поясах.
- Устранена проблема с дублированием событий при повторной синхронизации.

### Изменено
- Полностью переработана структура `README.md`:
  - добавлены бейджи статуса и ссылки на соцсети,
  - улучшено описание проекта,
  - добавлены разделы со скриншотами, видео-туториалом, FAQ,
  - исправлено отображение структуры проекта.
- Обновлён файл `LICENSE` – указан год 2026 и полное имя автора.
- Внесены мелкие правки в оформление кода (комментарии, отступы) для улучшения читаемости.
