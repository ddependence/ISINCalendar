# Changelog

Все значимые изменения в проекте «ISIN Calendar (Купонный Календарь)» будут отражены в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/), и проект придерживается [Semantic Versioning](https://semver.org/).

## [1.0.0] – 2026-08-26

### Добавлено

#### Основной функционал
- Основной скрипт `isin_calendar.py` для автоматической синхронизации купонов облигаций с Google Календарём.
- Автоматическое чтение списка ISIN из фиксированного файла `isin_list.txt` (без необходимости указывать путь в аргументах командной строки).
- Получение актуальных данных по купонам с публичного API Московской биржи (MOEX) без ключей и регистрации.
- Автоматическое создание событий в Google Календаре с указанием:
  - названия облигации,
  - даты выплаты,
  - суммы купона в рублях.
- Удаление событий для ISIN, которые были удалены из файла со списком.
- Предотвращение дублирования событий при повторных запусках скрипта.
- Установка напоминания за 24 часа до даты купонной выплаты.
- Поддержка OAuth 2.0 авторизации в Google с сохранением `token.json` для повторных запусков без повторной авторизации.
- Обработка пагинации при получении событий из календаря (до 2500 событий за один запрос).

#### Документация
- Подробный `README.md` с:
  - описанием проекта и его преимуществ,
  - пошаговой инструкцией по установке и настройке Google Cloud Console,
  - примерами использования и выводом консоли,
  - структурой проекта,
  - инструкцией для пользователей Windows,
  - решением проблемы синхронизации с Android (Poco / Xiaomi HyperOS),
  - разделом FAQ,
  - планами по развитию,
  - ссылками на социальные сети.
- `CHANGELOG.md` для отслеживания изменений (этот файл).
- `CONTRIBUTING.md` для желающих внести вклад в проект.
- Лицензия MIT с указанием автора (Aleksey Mortin).

### Изменено

#### Код
- Переименован основной скрипт с `add_coupons_to_calendar.py` на `isin_calendar.py` для соответствия названию проекта.
- Убрана необходимость указания пути к файлу ISIN через аргумент командной строки – теперь скрипт автоматически ищет `isin_list.txt` в текущей папке.
- Добавлена проверка наличия файла `isin_list.txt` с выводом понятной ошибки и ссылкой на пример.
- Добавлена проверка наличия файла `credentials.json` перед запуском с понятной инструкцией.
- Переход на UTC в запросах к календарю (вместо фиксированного `+03:00`) для корректной работы в разных часовых поясах.
- Добавлены таймауты (`timeout=10`) для всех HTTP-запросов к API Мосбиржи.
- Улучшена обработка ошибок:
  - перехват исключений при запросах к MOEX,
  - обработка ошибок авторизации Google,
  - обработка ошибок чтения и записи файлов,
  - обработка некорректных дат.

#### Документация
- Полностью переработана структура и содержание `README.md`:
  - добавлены бейджи статуса проекта,
  - добавлены ссылки на социальные сети,
  - улучшено описание и преимущества проекта,
  - добавлены разделы со скриншотами, видео-туториалом, FAQ,
  - исправлено отображение структуры проекта (древовидный список),
  - обновлена инструкция по настройке Google Cloud Console,
  - добавлена ссылка на официальную документацию Google Calendar API.
- Лицензия обновлена: указан год 2026 и полное имя автора (Aleksey Mortin).

#### Инфраструктура
- Настроен GitHub Pages для создания сайта документации (опционально).
- Обновлены темы (Topics) репозитория для улучшения поиска.
